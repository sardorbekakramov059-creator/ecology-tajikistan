# Экологияи Тоҷикистон — версияи ислоҳшуда

## Оғози зуд дар Windows
1. ZIP-ро пурра Extract All кунед.
2. `start-site.bat`-ро ду маротиба пахш кунед (Python лозим аст).
3. Браузер дар `http://127.0.0.1:8000` кушода мешавад.

Агар Python насб нашуда бошад, `index.html`-ро мустақим кушоед. `index.html`, `style.css` ва `script.js` бояд дар як папка бошанд. Аз дохили ZIP кушодан тавсия намешавад.

## Файлҳо
- `index.html` — сохтори сомона
- `style.css` — намуди равшан ва мутобиқ ба экран
- `script.js` — саҳифаҳо, муфассалот, галерея, шакли дархост ва харита
- `start-site.bat` — оғози сервери маҳаллӣ дар Windows

## Харита
Харита бо Leaflet ва OpenStreetMap кор мекунад ва барои намоиши харита пайвасти интернет лозим аст. Агар китобхонаи харита дастрас набошад, паёми алтернативӣ ва истиноди OpenStreetMap нишон дода мешавад. Нишонаҳо нуқтаҳои ҷойгиршавӣ мебошанд, на ҳудуди ҳуқуқии мамнуъгоҳҳо.

## Сабти дархост
Шакли дархост маълумотро дар `localStorage` нигоҳ медорад. Агар браузер инро манъ кунад, сомона боз ҳам кор мекунад, аммо маълумот танҳо то баста шудани ҳамин саҳифа муваққатан нигоҳ дошта мешавад. Барои қабули марказӣ аз ҳамаи меҳмонон API ва пойгоҳи додаҳои серверӣ лозиманд.
